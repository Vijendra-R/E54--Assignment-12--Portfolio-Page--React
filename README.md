# E54 Assignment 12 - Portfolio Page (React)

A responsive personal portfolio created using React, Bootstrap and React-Bootstrap.

## Technologies

- React
- React-Bootstrap
- Bootstrap 5
- Vite
- JavaScript

## Features

- Responsive navigation bar
- Hero section
- About section
- Skills with progress bars
- Project cards
- Statistics section
- Contact form
- Contact modal
- Responsive design
- Smooth scrolling
- Bootstrap components

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## GitHub

Create a GitHub repository and push the complete project.
